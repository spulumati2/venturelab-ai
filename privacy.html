VENTURELAB · PRIVACY

Privacy notice

Last updated: November 13, 2026

What this app stores

VentureLab stores game progress (such as virtual cash, investments, generated fictional startups, lesson progress, and simulation history) in your browser's local storage. This information stays in the browser on the device where you use the app unless you export a save file or your browser/device otherwise synchronizes its data.

What this app does not do

This version does not create user accounts, send game data to a VentureLab server, use analytics, sell personal information, or call an external AI API. The mentor uses a built-in educational knowledge base. The startup generator uses randomized fictional templates.

Save files

If you export your game, the downloaded JSON file contains your game state. Keep it private if you do not want someone else to see your game progress. Import only save files you trust.

Public website

The app can be hosted on GitHub Pages. A published website and its source repository may be publicly accessible. Do not add passwords, private information, API keys, or other secrets to the repository or game.

Children and students

This is an educational simulation. Do not enter personal or sensitive information. If you have questions about the hosting platform's privacy practices, review that platform's own privacy information with a parent or guardian.

Changes

This notice describes the current free, browser-only version. If future versions add accounts, analytics, external AI services, or cloud storage, this notice must be updated before those features are used.
